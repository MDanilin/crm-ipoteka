06 / Principles

Принципы визуального языка

Шесть правил, которым подчиняются все экраны.

01 · Воздух

Дыхание
важнее плотности

Большие отступы (20–24px между блоками), щедрые радиусы. Никогда не упирать текст в край.

02 · Тёплый акцент

Мандарин — для
действия

Один акцентный цвет на экран. Используем его в CTA, активном состоянии, индикаторах прогресса.

03 · Контраст веса

Bold + Light

В заголовках Manrope 700 — основа, 300 + мандарин — акцентное слово. Это даёт ритм без курсива и засечек.

04 · Безопасность

Изумрудный = доверие

Verified-метки, защищённая сделка, гарантия — всегда emerald + щит. Никогда mandarin для безопасности.

05 · Soft tints

Категории — пастель

Каждая категория — свой soft-tint фон + эмодзи. Облегчает беглое сканирование без перегруза цветом.

06 · Без слопа

Меньше элементов —
больше смысла

Никаких лишних иконок, цифр-украшений, градиентов ради градиентов. Каждый элемент должен заработать своё место.
